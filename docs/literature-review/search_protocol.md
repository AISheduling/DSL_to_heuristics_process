# Протокол поиска литературы

Обзор для постановки научного вопроса: генерация эвристик и решателей с помощью LLM для задач планирования (RCPSP и смежных).
Критерии зафиксированы: 2026-10-06.

## 1. Как сформирован стартовый набор

Стартовые работы взяты из ТЗ руководителя (таблица пластов A–D в md-файле с заданием). Пласт A: FunSearch, EoH, ReEvo, MCTS-AHD, EoH-S, MoH, PathWise, RefineEvo, TIDE, G-LNS, A2DEPT, SimpleEvol, TRACE, HeuriGym. Пласт B: Luo–Vanhoucke–Coelho 2026, Tian et al. 2026, «LLM-правила для job shop 2026», «LLM-приоритеты в эволюционном поиске расписаний 2026». Пласт C: Luo et al. 2022, MAP-Elites-гиперэвристики, Guo–Vanhoucke–Coelho 2021, SMAC, irace. Пласт D: InstSpecHH, работы с абляцией состава контекста.
Чтение этих работ началось 2026-10-05, до того как были записаны критерии; критерии ниже применены к ним задним числом. Прочитанные работы ТЗ им удовлетворяют; остальные проходят отбор на общих основаниях (см. лог воронки).

Дополнительные работы найдены тремя способами:
- **систематические запросы** — после фиксации критериев (раздел 3);
- **снежный ком** — по спискам литературы прочитанных статей (в логе воронки указано, из какой статьи);
- **уточняющие поиски** — поиск конкретной статьи по названию или авторам, чтобы получить текст или выходные данные; работы, найденные попутно, внесены в лог (раздел 4).

Ключи работ: фамилия первого автора + год итоговой публикации (конференция / журнал); если её нет — год первой версии на arXiv; + короткое имя метода.

## 2. Критерии включения и исключения

### Включаем

| № | Критерий |
| --- | --- |
| I1 | Пласты A и B: LLM генерирует или улучшает эвристику, правило, функцию, параметры или код решателя для комбинаторной оптимизации, либо LLM принимает решения внутри алгоритма планирования |
| I2 | Пласт B: задача — планирование (RCPSP и его варианты, job shop, flow shop, open shop, другие задачи расписаний) |
| I3 | Пласт C: автоматический дизайн, выбор или настройка эвристик **без LLM** (GP-гиперэвристики, выбор алгоритма / правила по признакам инстанса, конфигураторы алгоритмов), в первую очередь для планирования |
| I4 | Пласт D: смежные работы, которые напрямую касаются осей обзора (гранулярность генерируемого кода, представление контекста, генерация под конкретный инстанс) |
| I5 | Есть собственный вычислительный эксперимент с численными результатами |
| I6 | Годы: пласты A, B, D — 2023–2026; пласт C — без ограничения по году |
| I7 | Язык: английский или русский; доступен полный текст |

### Исключаем

| № | Критерий |
| --- | --- |
| E1 | LLM только формулирует математическую модель для MIP / CP-солвера и не генерирует эвристику или решения |
| E2 | LLM сама решает инстанс целиком в промпте (LLM-как-оптимизатор) без эвристики или кода — кроме работ, которые сравнивают это с генерацией эвристик |
| E3 | Обзоры и позиционные статьи без собственного эксперимента (используются только для снежного кома) |
| E4 | Тезисы и короткие статьи без описания метода и постановки эксперимента |
| E5 | Нет доступа к полному тексту |
| E6 | Дубликат: более ранняя или неполная версия уже включённой работы (оставляем самую полную) |
