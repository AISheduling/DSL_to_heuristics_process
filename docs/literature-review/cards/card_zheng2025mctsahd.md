| 12. Стоимость | Бюджет — T = 1 000 оценок функций на D (2 000 для онлайн BPP), одинаковый для всех LLM-AHD-методов, — то есть сравнение уравнено по числу оценок. По вызовам LLM не уравнено: MCTS-AHD делает 2 вызова на функцию (код + описание). Результат и ограничения | Поиск по дереву вместо популяции даёт лучшие функции, чем EoH, ReEvo, FunSearch и HSEvo, на большинстве задач при равном числе оценок; выигрыш тем больше, чем сложнее пространство эвристик (оценка через o1-mini).
