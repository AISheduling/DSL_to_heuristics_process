# ADR 0002. Стандартные индикаторы проекта и данные PSPLIB

- Дата: 2026-10-21
- Статус: черновик (до построчной сверки с RCPLIB)
- Связано: ADR 0001, `card_guo2021prselection.md`, этап A плана перехода на PSPLIB и синтетику

## Контекст

Метаданные DSL (`graph_meta_characteristics`, `src/calculate_metrics.py`) содержат только
сетевые характеристики графа и несопоставимы с литературой: OS делится на `n(n−1)` вместо
`n(n−1)/2` и считается с фиктивными работами; CPL, `relative_cpl`, плотность и параллелизм
не входят в стандартный набор; ресурсных индикаторов нет. Для сравнения с
guo2021prselection нужны их 12 индикаторов (табл. 2 статьи), посчитанные так же, как в
RCPLIB (Excel-файл группы OR&S, UGent). Сервер OR&S 2026-10-21 недоступен, поэтому
договоренности ниже подобраны по диапазонам min/max из табл. 3–4 guo2021 на полных
наборах PSPLIB J30/J60/J120 (1560 инстансов).

## Решение

1. **Данные.** PSPLIB J30 — отладка и настройка, J60/J120 — финальный тест; скачиваются
   по `data/psplib/SOURCES.md` (с SHA-256), в git не хранятся. Парсер `src/psplib.py`
   переводит `.sm` в формат `data/processed`; `j301_1.sm` дает в точности
   `Case1_PSPLIB_j301_1.json`. Весенние 5 постановок остаются только для воспроизведения.
2. **Модуль** `src/indicators.py` не импортирует каркас; вход — инстанс `data/processed`.
   Область применимости — одномодовый RCPSP с возобновляемыми ресурсами. Невозобновляемые
   ресурсы, группы выбора, режимы и многопроектные инстансы — `IndicatorError`
   (для Case 5 индикаторы считать по проектам отдельно).
3. **Фиктивные работы** (длительность 0 и нет спроса) исключаются из `n`, уровней и
   ресурсных индикаторов; дуги к ним и от них не считаются. Транзитивная редукция
   не делается: индикаторы считаются по дугам как в файле.
4. **Формулы.** `n` — реальные работы, `A` — дуги между ними, `PL` — прогрессивный уровень
   (1 без предшественников, иначе max PL предшественника + 1), `m = max PL`, `W_a` — число
   работ на уровне `a`, `RL` — регрессивный уровень (m без преемников, иначе
   min RL преемника − 1). Ресурс `k` с мощностью `a_k`, спрос `r_ik`.

   | Индикатор | Формула | Источник |
   |---|---|---|
   | CNC | `|A| / n` | Pascoe 1966 |
   | OS | пары в транзитивном замыкании / `(n(n−1)/2)` | Mastor 1970 |
   | SP (I2) | `(m−1)/(n−1)` | Vanhoucke et al. 2008 |
   | AD (I3) | `α_w / α_max`, `α_w = Σ|W_a − n/m|`, `α_max = 2(m−1)(n/m − 1)`; 0 при `m ∈ {1, n}` | там же, шкала обратная (п. 5) |
   | LA (I4) | `(n'_1 − n + W_1) / (D − n + W_1)`, `n'_1` — дуги длины 1 по уровням, `D = Σ W_a W_{a+1}`; 1 при `D = n − W_1` | там же |
   | I5 | `(Σ_{l≥2} n'_l (m−l−1)/(m−2) + n'_1 − n + W_1) / (|A| − n + W_1)`; 1 при `|A| = n − W_1` | там же |
   | TF (I6) | `Σ (RL_i − PL_i) / ((m−1)(n−m))`; 0 при `m ∈ {1, n}` | там же |
   | RF | `Σ_i Σ_k [r_ik > 0] / (nK)` | Pascoe 1966 |
   | RU | среднее по работам число используемых ресурсов | Demeulemeester et al. 2003 |
   | RS | среднее по ресурсам `(a_k − r_k^min)/(r_k^max − r_k^min)`, `r_k^min = max_i r_ik`, `r_k^max` — пик спроса в раннем расписании CPM; 1 при `r^max = r^min` | Kolisch et al. 1995 |
   | RC | среднее по ресурсам `mean_{i: r_ik>0} r_ik / a_k` | Patterson 1976 |

   Ресурс, который никто не использует, в RS и RC не входит.
5. **AD.** У Vanhoucke 2008 I3 = 1 для равномерного распределения работ по уровням.
   Диапазоны guo2021 воспроизводятся только с обратной шкалой `α_w / α_max`
   (0 — равномерно): прямая дает для J30 [0.48; 0.89] против табличных [0.11; 0.52].
   Принята шкала RCPLIB.
6. **Дополнительные признаки** (блок `extended`, в сравнение с guo2021 не входят) — для
   синтетических сценариев, которые стандартные 12 не различают: `max_duration_share`
   (гигантская работа), `max_descendant_share` (узкое горлышко), `cpm_length`,
   `cpm_to_total_duration`, `min_rs` (самый дефицитный ресурс), `duration_cv`, `demand_cv`.
7. **Версия набора** — поле `standard: "guo2021-v1"`; любое изменение формул меняет версию.
   `calculate_metrics.py` не меняется: весенние DSL и результаты остаются как были.

## Сверка (tests/test_indicators.py)

Min/max каждого индикатора по J30, J60, J120 сравниваются с табл. 3–4 guo2021 (два знака).

- Совпадают: n, CNC, SP, I5, TF, RU, RS на всех трех наборах; OS, AD, LA — на всех,
  кроме трех границ, где расхождение ровно в одну единицу второго знака: OS J60 max
  0.5446 (табл. 0.55), AD J120 min 0.1846 (0.19), LA J120 min 0.0008 (0.01). Скорее всего,
  это округление в таблице; тест допускает ±0.01.
- RF: в таблице уровни генератора ProGen (0.25, 0.50, 0.75, 1). Посчитанный RF принимает
  в каждом наборе ровно 4 значения, каждое ближе 0.01 к своему уровню.
- **RC, открытый вопрос.** Минимум совпадает, максимум выше табличного: J30 0.6416 (0.61),
  J60 0.5036 (0.49), J120 0.5135 (0.50). Проверены варианты: отношение сумм по ресурсам,
  среднее по всем работам, медиана спроса, максимум и минимум по ресурсам, знаменатель
  с фиктивными работами — ни один не дает обе границы на всех наборах. Тест допускает
  отклонение до 0.04 и помечает его как известное.

## Последствия

- Когда появится RCPLIB (`data/rcplib/SOURCES.md`), добавить построчную сверку всех
  12 индикаторов, закрыть вопрос RC и проверить RU (среднее или максимум по работам:
  на PSPLIB диапазоны [1; 4] не различают эти варианты), затем перевести ADR в «принято».
- Блок индикаторов в DSL, промпты и `DSLParser` переводятся на этот модуль на этапе D.
