# RCPLIB: источник

Индикаторы проектов (12 штук, как в guo2021prselection) и лучшие известные решения
для наборов RCPSP — Excel-файл на странице группы OR&S (Ghent University):
https://www.projectmanagement.ugent.be/research/data

Положить файл сюда (`data/rcplib/`), в git он не хранится. После загрузки дописать
имя файла, дату и SHA-256.
